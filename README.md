# LAST TRACE — 사라진 최종본

금요일 밤, 논문의 최종본이 지워졌다.  
토요일 아침, 당신은 취조하지 말라는 말을 듣고 연구실 문을 연다.

다섯 명의 학부연구생이 기다린다.  
한 명은 코인 차트에서 눈을 떼지 못하고, 한 명은 사진을 아끼고, 한 명은 서버 열쇠를 갖고 있다. 한 명은 밴드 연습을 가고, 한 명은 방에서 드라마를 본다.

오늘은 연애 시뮬레이션처럼 시작한다.  
호감은 마음이고, 선입견은 소문이다. 사라진 파일은, 그들이 내밀 때 연다.

녹음 속에 숨은 파장, 사진 파일의 끝, 메모리에 남은 주문, 복도의 출입 기록.  
사람들이 먼저 의심한 이름과, 기록이 가리키는 이름은 다를 수 있다.

---

## 실행

브라우저에서 하는 게임이다. 따로 설치할 것은 없다.

게임 폴더에서 서버를 켠다.

```bash
python -m http.server 8765
```

브라우저에서 [http://127.0.0.1:8765/](http://127.0.0.1:8765/) 를 연다.

`index.html`을 더블 클릭해도 대부분 켜진다. 그림이나 영상이 비어 보이면 위의 주소로 다시 연다.

## 플레이

1. **이야기를 시작한다.** 이어서 할 때는 **기록을 이어간다.**
2. 대사 창을 클릭하거나 `Enter`, `Space`로 넘긴다. 방금 대사를 되돌릴 때는 **BACK**.
3. 선택지는 호감만 바꾼다. 누가 파일을 지웠는지는 선택지로 정해지지 않는다.
4. 상대가 파일을 내밀면 그 파일을 연다. 분석이 끝나면 **수첩에 남긴다.** 접어 두면 이야기는 그 자리에서 기다린다.
5. 오른쪽 위 **수첩**, 또는 `N`. 카드 앞면은 소문이고, 뒷면은 직접 연 기록이다. 카드를 누르면 뒤집힌다.
6. 한 사람의 이야기가 끝나면 임시 방으로 돌아온다. 다음 장소는 그때 열린다.
7. 다섯 명을 만난 뒤, 왼쪽의 **연구실에 보고한다**를 누른다.
8. 초상화 다섯 장의 뒷면을 모두 펼친 다음, 한 사람을 지목하고 **보고한다.**
9. 기록이 그 이름을 받아 주지 않으면 반박이 돌아온다. 수첩을 다시 보고 고를 수 있다.

수첩 안의 **기록을 지운다**는 호감과 카드 뒷면을 함께 비운다.

## 만나기 전에

소문만 적어 둔다. 뒷면은 플레이하면서 채운다.

- **혜진** — 학교 앞. 화면의 빨간 숫자와 같이 앉아 있다. 목소리는 크다.
- **혜선** — 정문 쪽. 혼자 있는 시간을 아낀다. 어젯밤은 집이었다고 한다.
- **솔미** — 연구실. 저장소를 맡았다. 사람들이 가장 먼저 이름을 꺼낸다.
- **지희** — 학생회관. 학생회와 밴드부를 오간다. 먼저 말을 건다.
- **민영** — 기숙사. 방에서 드라마를 본다. 목소리를 높이지 않는다.

수첩 앞면에는 이미 이 소문이 적혀 있다.  
당신이 믿을 사람과, 당신이 보고할 사람은 같은 이름일 필요가 없다.
