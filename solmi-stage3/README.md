# 솔미 Stage 3 — 사라지지 않은 기록

## 구성
- `js/memory-stage3.js`: 기존 게임의 `MINI.memory`에 연결할 Stage 3 분석 화면 함수
- 상위 프로젝트의 `js/minigames.js`에는 이 함수가 이미 통합되어 있습니다.

## 구현 내용
- 웹게임 안에서 HxD의 핵심 화면을 재현한 교육용 메모리 분석기
- Offset / Hexadecimal / Decoded text 표시
- 문자열 검색 및 Unicode(UTF-16LE) / ASCII 표시 전환
- Ctrl+F 검색창 포커스
- 3단계 힌트
- 주문번호 확인 후 Stage 3 완료 처리

## 플레이 방법
1. 기존 게임을 실행하고 솔미 Stage 3를 엽니다.
2. `23:14`를 Unicode로 검색해 사건 시각 주변 기록을 확인합니다.
3. `order_id=7731`을 검색해 주문번호를 확인합니다.
4. 주문번호 `7731`을 제출합니다.

## 주의
이 화면은 수업에서 배운 HxD의 검색·헥스·문자 디코딩 개념을 웹에서 연습하도록 만든 **교육용 시뮬레이터**입니다. 실제 운영체제 RAM을 수집한 덤프 파일이나 실제 HxD 프로그램은 아닙니다.
